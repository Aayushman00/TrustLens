# TrustLens Frontend (Phase 1)

Minimal Vite + React + TypeScript page. No MUI, no auth, no evaluation UI.

## Run

```powershell
cd frontend
npm install
npm run dev
```

Or from repo root: `.\scripts\dev-frontend.ps1` / `make dev-frontend`

Opens on `http://localhost:5173`. Optionally shows backend health from `http://localhost:8000/health`.
