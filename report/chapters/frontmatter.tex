\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
Downloading a classifier from a public model hub takes one line of code, but deciding whether it deserves to be used is harder: the information at hand is a free-text model card, a possibly empty licence field and no standard evidence about behaviour on sensitive groups. \textbf{TrustLens} is a semi-automated research prototype that collects this evidence for Hugging Face text-classification models and organises it around the five FRIES dimensions: Fairness, Robustness, Integrity, Explainability and Safety. It imports a model, runs five automated tests (probes) locally, stores the evidence in files named by their SHA-256 hashes, converts it into Occurrence/Severity/Detection (O/S/D) ratings, three scales borrowed from Failure Mode and Effects Analysis (FMEA), and produces a versioned report. The primary output is a five-dimensional audit profile; the aggregate FRIES score is a secondary summary. The behavioural experiments cover one task, English-language toxicity classification on the Civil Comments dataset.

We tested the system on nine controlled models with injected flaws, on progressively larger injected defects, with a fairness test planned before it was run, against a large language model (LLM) reading the same evidence, with a blinded human review of evidence packets, and in a descriptive audit of seven real Hub models. Measurements from the automated probes were identical across five repeated runs, and they moved with the defect level in every experiment that returned a measurement. Rescaling the score to the range of the injected defects widened it from 0.68--1.18 to 4.60--6.65 points. Treating missing documentation separately from observed problems removed the false flags on clean controls. A rule on the gap in true-positive rates between two groups flagged every injected disparity once 40\% or more of one group's training labels had been flipped, on data the rule had not seen.

Several results were negative. The planned robustness sweep withheld a rating at every level. The fairness rule also flagged the real reference model. The LLM comparison was inconclusive: all 60 planned calls returned valid answers, yet they agreed with the deterministic layer on only 11 of 36 packet--dimension pairs. The scores separate synthetic defect levels but are not calibrated to real-world harm. The fairness groups come from an annotator-reported identity-attack signal. The integrity check confirms agreement with a reference hash for the weight file the worker loaded, which says nothing about backdoors. The human review and the Hub audit are exploratory (Section~\ref{ch:limits}).

TrustLens is meant to help a human reviewer see where the evidence is strong and where it is thin.
