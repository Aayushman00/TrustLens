# M0 + M1 (Foundation and TrustBench-C v0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the v1 statistics bugs, remove the LLM path, add the counts-based evidence contract and opcode scan (M0, wk 1–4), then train TrustBench-C v0 (122 controlled models) and produce the probe scorecard that G1 is decided from (M1, wk 5–12).

**Architecture:** New pure cores live beside v1 code, not inside it: `backend/app/posterior/` (exact intervals), `backend/app/evidence/schema.py` (EvidenceItem), `backend/app/integrity/opcode_scan.py`. New probes are pure functions over (model callable, rows) that return `EvidenceItem`; they are not wired into the Celery pipeline in M1 (that is M3). TrustBench lives in `backend/app/trustbench/` (generators promoted from `scripts/prepare_flawed_suite_data.py` + `scripts/train_flawed_suite.py`, manifest, scorer). v1 probes stay untouched except the K11–K13 fixes.

**Tech Stack:** Python ≥ 3.11, pytest, stdlib + scipy (`scipy.stats.beta`; already in `backend/uv.lock`, declare it explicitly), torch/transformers (existing `robustness` extra), BERT-base on the RTX 4060.

**Spec:** `docs/v2/07-roadmap.md` (M0, M1, G1), `docs/v2/DESIGN_SYNTHESIS.md` §5–7, `docs/v2/01-v1-baseline-and-known-issues.md` (K-items, bug-hunt protocol), `docs/v2/02-probe-redesign.md`, `docs/v2/04-trustbench-ground-truth.md`, `docs/adr/0014-hard-fail-evidence-policy.md`. Seed code: `docs/v2/spikes/s3_*.py`, `s4_*.py`, `s5_*.py`, `s7_*.py`.

## Global Constraints

- No LLMs in measurement, scoring, decisions or reports.
- Rate estimands MUST carry `counts {k, n}`; percentile bootstrap and Wald are not allowed for rates.
- Never max − min across groups for a decision statistic; gaps are signed vs `pooled`.
- Tier A = versioned denylist hit only (`integrity/denylist-v1`); unknown callable = Tier B. The scanner never unpickles.
- Test split (30 % of models, by model) is written to the manifest and never scored in M0/M1.
- Pre-registration file committed **before** any scorecard number is generated.
- GPU path rounds predictions to 4 dp before hashing.
- Commits: no Claude co-author / attribution trailer (project rule, spec 06).
- Work on a `v2/m0-m1` branch off `v2/specs`; `Main` stays at v1.

## Review Focus

1. **k = 0 or k = n in a Jeffreys interval** (no flips, all missed): expect a finite interval with lo = 0 or hi = 1, no NaN. → Task 3 test `test_jeffreys_edges`.
2. **A group that vanishes after filtering or in a bootstrap replicate**: expect `insufficient_evidence`, never a silent drop. → Task 4 tests `test_signed_gap_small_group_insufficient`, `test_bootstrap_reports_dropped_replicates`.
3. **Counterfactual sentence where no lexicon term occurs**: expect the row to be excluded from n, not counted as a non-flip. → Task 8 test `test_counterfactual_skips_rows_without_identity_term`.
4. **Truncated / non-pickle / zip-without-.pkl weight file**: expect Tier B `scan_not_possible`, never Tier A and never a crash. → Task 6 test `test_scan_garbage_is_tier_b`.
5. **Re-running the generator or trainer after a crash halfway through 120 models**: expect it to skip finished models and not overwrite weights. → Task 11 test `test_train_all_skips_existing`.
